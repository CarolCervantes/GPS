Instala DiaMon

El código abre esta página en el celular. Desde ahí descargas la app Android o entras a la versión web.

App Android (APK)

Versión 1.2.0 · Android 7.0 o superior · 5 MB
  1. Toca Descargar APK y abre el archivo cuando termine.
  2. Si el celular lo pide, permite "Instalar apps desconocidas" para Chrome o para Archivos.
  3. Si ya tenías una versión anterior de DiaMon, desinstálala primero.
  4. Inicia sesión. Si eres paciente, acepta la ubicación con "Permitir todo el tiempo".
